# 英文法ツール

英文法の解説を読み、英短文を「文型」「文の種類」「時制」で種類分けして練習できるツールです。
HTML・CSS・JavaScript だけで作っていて、外部ライブラリは使っていません。スマートフォンでも使えます。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバーは不要です）。

画面下のタブで 3 つの機能を切り替えます。

| タブ | できること |
|---|---|
| 解説 | 13 の文法項目（5文型・文の種類・時制・助動詞・受動態・比較・不定詞・動名詞・関係代名詞・仮定法など）の要点・例文・間違えやすい点を読めます。項目名で検索できます。 |
| 種類分け一覧 | 92 の英短文を、文型／文の種類／時制で絞り込んで表示します。文をタップすると日本語訳と解説が開きます。 |
| 練習 | 英文が 1 文ずつ出るので、その種類を選びます。正答率・連続正解数を表示し、間違えた文だけを出し直すこともできます。 |

- 時制の分類では、命令文は時制を持たないため対象から外しています。
- 練習の成績はブラウザに保存されます。保存できない環境（プライベートブラウズなど）でも練習はできますが、成績はページを閉じると消えます。

## ファイル構成

```
index.html     画面の骨組み
style.css      レイアウト・配色（スマートフォン基準、画面幅 768px 以上で 2 列、ダークモード対応）
grammar.js     文法解説のデータ（GRAMMAR_TOPICS）
sentences.js   英短文のデータ（SENTENCE_ROWS）と分類の定義（AXES）
app.js         タブ切り替え・絞り込み・練習の処理
```

## データの追加

- 英短文を増やすときは、`sentences.js` の `SENTENCE_ROWS` に
  `[英文, 日本語訳, 文型, 文の種類, 時制, 解説]` の形で 1 行追加します。
  記号の意味はファイル先頭のコメントを見てください。
- 文法項目を増やすときは、`grammar.js` の `GRAMMAR_TOPICS` に項目を追加します。
